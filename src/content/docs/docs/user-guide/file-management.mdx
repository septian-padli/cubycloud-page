CubyCloud provides a responsive, web-based file explorer for managing documents, media, and archives.

## Workspaces: My Storage vs. Organization

When navigating the file drive, you have access to two primary sections:

1. **My Storage (`/drive/my-storage`):** Your private workspace. Folders and files in My Storage count against your account quota. You control access by sharing individual items or creating public links.
2. **Organization (`/drive/organization`):** A shared file repository accessible to all registered users on the server. Every authenticated user can read, write, and delete files in this tree. Organization files consume physical storage node capacity but do not deduct from personal user quotas.

## File & Folder Operations

The file explorer toolbar and item context menus provide standard drive actions:

- **New Folder (`+ Tambah` / `Add`):** Create subdirectories to organize files.
- **Upload Files & Folders:** Upload individual items or entire directory hierarchies.
- **Rename (`Ganti nama`):** Change item names. If a conflicting name exists in the folder, CubyCloud presents a rename dialog with a suggested unique name.
- **Move (`Pindahkan`):** Move items across directories using an interactive folder tree browser. Moving a folder into itself or its subdirectories is automatically prevented.
- **Duplicate (`Salin`):** Creates an instant pointer copy in the database without duplicating physical storage bytes.
- **Star / Unstar (`Bintangi`):** Pin frequently accessed files for quick retrieval under the **Starred** navigation view.
- **Compress to ZIP (`Kompres ke ZIP`):** Queues an asynchronous background job to bundle selected files into a zip archive inside the current folder.
- **Batch Download ZIP (`Unduh ZIP`):** Select multiple files and folders to download them bundled as a zip file on the fly.

## Upload Mechanics & Resumption

CubyCloud selects the optimal upload protocol based on file size:

- **Direct Uploads (< 50 MB):** Single-request multipart form upload for swift transfers.
- **Resumable Chunked Uploads (≥ 50 MB):** Uses the open TUS protocol with 5 MB chunks stored temporarily under `/app/data/temp/tus`.

If your connection drops during a large upload:
1. Re-add the same file to the upload queue.
2. The browser calculates the file hash and client fingerprint.
3. The server resumes the upload from the exact last uploaded chunk.

## In-Browser File Previews

Click any supported file in the list to open the full-screen preview modal without downloading the file:

| Category | Supported Formats | Preview Capabilities |
| :--- | :--- | :--- |
| **Images** | PNG, JPEG, GIF, WebP, SVG | Full-resolution pan and zoom. |
| **Video** | MP4, WebM | Native HTML5 video player with seek support. |
| **Audio** | MP3, WAV, OGG | Inline audio playback. |
| **Documents** | PDF | Paginated document viewer. |
| **Code & Text** | TXT, MD, JSON, JS, TS, GO, PY, HTML, CSS | Formatted code viewer with syntax highlighting and line numbers. |

## Trash & Retention

When you delete an item from **My Storage**, it moves to the **Trash (`/drive/trash`)**:

- **Restore (`Pulihkan`):** Restores the item to its original parent folder. If the parent folder was deleted in the interim, the item is restored to the root directory.
- **Delete Permanently (`Hapus Selamanya`):** Immediately removes the database record and marks physical storage blobs for background pruning.
- **Automatic Purge:** By default, items residing in the Trash for more than 30 days are automatically purged by a hourly background cleanup worker.

<Aside type="note" title="Trash is not an offsite backup">
  Trash protection shields users from accidental deletions, but it does not protect against disk failure or database corruption. Operators must maintain regular database and volume backups.
</Aside>
