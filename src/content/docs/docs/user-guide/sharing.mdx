CubyCrate supports sharing selected My Storage files and folders with registered users or through public links.

<Aside type="note" title="Organization is already shared">
  Every authenticated user can access the shared Organization tree. It does not have separate per-team permissions. The sharing guide applies to My Storage items.
</Aside>

## Share with a registered user

My Storage items can be granted to registered accounts using **Viewer** or **Editor** access. The application checks permissions for each action. Available edits depend on the item and share scope.

## Create a public link

Public links let people access a shared item without a registered account. A link can be password-protected. Keep the link private if its contents are not public; revoke it when access is no longer needed.

## Manage access

Review active shares from the item's sharing controls. Update or revoke access when it is no longer needed. Do not assume sharing changes will move or copy the underlying file.
