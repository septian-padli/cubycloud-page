## What is CubyCrate?

CubyCrate is a self-hosted file drive. A Go server provides the API and embedded web interface in one container. SQLite stores application metadata, while file data lives on local filesystem or S3-compatible storage nodes.

## Core capabilities

- Manage files and folders in My Storage and the shared Organization tree.
- Upload, download, rename, move, duplicate, star, and restore files from Trash.
- Resume supported uploads in My Storage and Organization.
- Preview supported images, video, audio, PDF, and text files in the browser.
- Share My Storage items with registered users as Viewer or Editor, or create public links with optional password protection.
- Configure local and S3-compatible storage nodes through the administrator interface.

## Storage and capacity

CubyCrate separates file metadata in SQLite from physical file data on storage nodes. Administrators can configure local filesystem paths or S3-compatible storage.

My Storage uses personal quota limits. Organization is one shared tree available to authenticated users and is not charged against individual user quotas. Both workspaces still consume physical storage-node capacity. Configured capacity limits and actual free space are distinct measures.

<Aside type="caution" title="Organization permissions">
  Organization is a shared tree for authenticated users. It does not provide separate team spaces or granular group permissions.
</Aside>

Local and S3 storage are choices, not automatic replication, synchronization, or high availability. Operators manage backups for application data, external mounts, and object storage.
