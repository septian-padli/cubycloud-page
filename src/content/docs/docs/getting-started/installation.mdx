## Before You Begin

Prepare a host and decide who will operate it before you deploy. A self-hosted drive depends on infrastructure that you maintain.

## Prerequisites

- A host capable of running the published container, according to the product repository.
- Persistent storage for application data and files.
- A plan for network access, HTTPS, and backups.

<Aside type="danger" title="Verify before deploying">
  Exact runtime requirements and supported configuration values are intentionally omitted here until checked against the product source.
</Aside>

## Deployment Overview

The application packages a Go backend and embedded web interface in a single container. SQLite stores application data; files use configured local filesystem storage or optional S3-compatible object storage.

## First Launch

After following the verified deployment instructions, open the web interface and complete the first-administrator setup in the browser. Confirm that persistent storage, access controls, HTTPS, and backups meet your own operational requirements.
