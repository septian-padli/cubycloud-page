CubyCrate provides a browser-based file manager for personal and shared files.

## Workspaces

- **My Storage** is each user's personal file area. Its files count toward that user's quota. Users can share selected items.
- **Organization** is one shared tree for authenticated users. Its files use physical storage capacity but do not count against an individual user's quota. Organization does not provide group-level permission boundaries.

Administrators configure storage-node capacity separately from user quotas. Physical free space may limit uploads even when a user's quota has room.

## File operations

Available workflows include creating folders, uploading and downloading files, renaming, moving, duplicating, starring, and sending My Storage items to Trash. Available actions depend on the current workspace and the user's permissions.

The product supports image, video, audio, PDF, and text/code previews. The exact preview behavior depends on the file type and browser support.

## Uploads

CubyCrate supports direct uploads and resumable transfer flows. Network interruptions, configured storage capacity, and reverse-proxy limits can affect large uploads. If uploads fail behind a proxy, check its request-size and timeout settings in [Configuration & Reverse Proxy](/docs/getting-started/configuration/).

## Trash

My Storage items moved to Trash can be restored or permanently deleted. The application purges items kept in Trash beyond its retention period. Trash is not a backup. Maintain a separate backup of application data and physical files.

## Sharing

My Storage items can be shared with registered users using Viewer or Editor access. Public links may use password protection. See [Sharing](/docs/user-guide/sharing/) for details.
